# 星渊遗迹 2.0 交付说明

本次六项功能均已实现，复用现有20种升级、职业、素材、战斗循环与存档键；没有新增依赖。

## 规则与参数

集中配置位于 src/data/config.ts：命运三连3%，未触发时卡牌暴击15%（总升级事件中约14.55%）。先揭晓奖励再选择，无保底。三连点击一次“全部获得”；奖励完成后仅结算一次，积攒经验仍可正常连续升级。卡片带批次编号，旧批次操作不会影响下一次升级。

探索敌人生命×0.8、伤害×0.75；挑战×1/×1，沿用1.0；噩梦×1.4/×1.35。全部开放。无尽初始×1/×1，第8分钟后每分钟额外生命倍率增加0.15、伤害倍率增加0.12，连续线性增长。生命仍乘原有普通敌人随时间增长系数(1+秒数/360)，Boss没有这项原系数。伤害倍率在扣护甲前应用。无尽Boss只出现一次；死亡后恢复原有普通刷怪频率；速度的时间加成封顶在原11分钟数值。实体、弹体和特效上限不变。

多数原升级存在入池层数上限；保留筛选与原有耗尽后回退机制。暴击保证两层，允许最后一次奖励超过入池上限一层。生命回复照原逻辑受最大生命限制，不会溢出治疗。没有新增双倍技能版本。

## 查看与保存

主菜单选模式，暂停→角色与构筑→继续探索；Esc也可关闭面板恢复。属性直接读取战斗角色，显示基础伤害、间隔、范围等，不另算综合战斗力。本局升级次数不包含职业初始元素或彩蛋奖励，但它们已体现在实际属性中。

探索、挑战、噩梦各保留最快通关，用时相同取击败更多；无尽保存死亡时最长存活。结束/退出不伪造通关，无尽主动退出不提交最长成绩。纪录携带模式、难度、成绩、职业、等级、实际属性及升级层数的独立副本。旧1.0音量和累计成绩保留，没有历史构筑的旧成绩不会被捏造为新纪录。单条新纪录损坏则忽略该条。清除站点数据会丢失本地纪录，不跨设备同步。

## 交付与启动

源代码、网页产物及离线包位于 release/Starfall-Ruins-2.0-*.zip；离线HTML无需安装。所有美术和音频来源不变，沿用原许可记录。主要修改 config.ts、model.ts、storage.ts、main.ts、interface.ts、polish.css；新增小型 records.ts 负责快照与验证。

Node 22.12+、pnpm：`pnpm install`，`pnpm dev`开发；`pnpm build`构建；`pnpm serve`在4173提供本地网页；`pnpm build:offline`生成离线HTML。`pnpm test`运行核心测试。浏览器测试需要开发服务5173，发布测试另需4173；沿用项目现有Chrome/Edge及CHROME_PATH配置。

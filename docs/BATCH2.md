# 第二批本地验收：双元素锁定（2.2.0）

本批是规则中间验收版。只完成双元素锁定、选卡提示、三连安全候选和构筑/纪录显示。没有新增四种协同，没有改变已验收的难度参数，不发布公网。

## 规则

获得第二种不同元素后锁定本局组合。两种已持有元素仍可升级，其余两种不再入池；非元素卡保留原规则。暴击同一种元素增加两层，不占两个元素位置。术士开局虚空计入，预览明确提示只能再选一种。

普通三选一可展示多个不同的第二元素供选择；三连在展示前按洗牌顺序挑出全部领取后至多两种元素的三张卡。已展示奖励全部发放，不暗中吞卡，不叠加暴击。若兼容候选不足，沿用生命/伤害回退卡补足三张，不新增卡池。发奖前再整体校验一次，拒绝非法奖励批次，不部分发奖。

卡面提前提示选中后的组合，三连提示整批领取后的锁定结果。暂停构筑和结束快照显示锁定组合。新局清空锁定，术士恢复为仅初始虚空。旧纪录保持原有元素数值；缺少锁定字段时显示旧纪录未记录锁定，不伪造历史锁定。

现阶段只有火焰＋寒冰的熔裂、雷电＋虚空的坍缩已存在。其他四种组合可以锁定并使用两种元素的基础效果，但明确标注“协同效果待第三批实装”，不宣称具有新反应。六种完整协同的具体效果仍需第三批前确定。

# 2.1 本地验收版

本次不发布公网、不制作APK。沿用20种升级、敌人、职业、Boss、地图和音效；未新增依赖。入口 http://localhost:4173/ ，刷新后菜单底部显示2.1。

## 诊断与证据

已核实：伤害/间隔/范围乘算互相放大；大量击杀可无限次触发回复，护甲又按次抵扣伤害；额外升级加速这些成长。卡池耗尽回退会重新提供伤害牌，使无尽伤害继续指数成长，而原无尽敌人生命约二次增长、伤害线性增长。未发现无尽时间增长被意外关闭。

旧版既有走位脚本（种子75、挑战）三职业在488—506秒获胜，等级41—43，结束时接近或达到满血。固定41层构筑在无尽Boss后同等进度站桩120秒：骑士/术士/使徒分别承受61/54/43次伤害，但结束生命175/155/180，说明恢复确实掩盖大量受伤。固定15层版本会死亡，不能把“几次升级即可无敌”当作对所有构筑均成立的事实。

修改后同一41层样本在压缩后的对应进度分别39/49/69秒死亡。这个样本不代表所有地图、种子或构筑。输出压制也存在明显数值放大，但未穷举所有组合；以局部削减后续叠加处理，未删除协同、控制或弹体。

## 实际参数（src/data/config.ts）

- 时间：身份120秒、Boss240秒、崩塌360秒。无尽保持同开局，不因Boss死亡或崩塌终止。
- 经验：第一次8，之后每级门槛增加18（原6）。既有种子75挑战模拟成功的术士/使徒结束等级19/18；无额外奖励、偏进攻的噩梦术士在Boss前等级16，316秒获胜、结束等级19。12—15次是Boss前构筑参考，并非强制次数或保证每局达到。
- 仅伤害、攻击间隔、范围、护甲、再生、击杀回复递减：前两层不变，第n层的增量乘 1/(1+0.6×max(0,n−2))。乘数类递减的是增量部分；暴击仍按相邻两层逐次应用，不把两层简化为一次乘二。其余14种升级不改。
- 击杀回复共享3点额度，按战斗时间每秒补充3点、最多存3点；连续范围击杀不能瞬间吸回整条生命。再生、治疗牌、护盾、闪避机制保留。额度只在战斗推进时恢复。
- 基础难度HP/伤害：探索0.8/0.75、挑战1/1、噩梦1.4/1.35，均保持2.0初始值。第60秒起平滑增加，240秒达到额外倍率：探索1.35/1.25、挑战及无尽1.5/1.4、噩梦1.65/1.8。之后普通模式保持该倍率。
- 无尽在240秒后另乘：生命1.28^(经过分钟)、伤害1.22^(经过分钟)，持续增长，不增加实体上限或重复Boss。
- 普通敌人原时间HP系数改为1+时间/180（原/360）；刷怪间隔随时间缩短的分母650→325，下限仍0.3秒。普通敌人类型进入时间压缩为15/30/60/105秒；速度时间加成按两倍进度推进，仍封顶原+6.6。
- Boss基础HP6000→4200以适应更少升级；主范围攻击25→30、接触25→32，其他招式、攻击频率和预警时间不改。噩梦Boss实际HP9702；满额后基础范围伤害72.9，再正常扣护甲。没有无视防御或强制扣血。
- 三连3%、非三连时暴击15%，概率、互斥、奖励数量均未改。极短CSS亮起无需等待，可立即选；支持减少动态效果。卡面预览前后层数，领取后显示2层或三项的实际回执。连续升级会显示上一批奖励，旧批次仍不可重复发奖。

## 验证边界

固定15项常规构筑的三个职业，在隔离Boss且测试保护不受伤的条件下均有足够DPS在期限内击杀；关闭测试保护、原地硬吃则死亡。纯防御样本即使给予测试无敌，仍在时限因未击杀Boss失败。保护仅用于测试输出窗口，不代表实战走位能力。固定成型噩梦站桩场景也已添加回归断言。

既有简易走位脚本只做近敌回避与拾取，并非熟练玩家。种子75/76默认偏恢复选卡的噩梦模拟均未通关；种子75进攻选卡术士无需暴击/三连可通关。骑士、使徒有隔离Boss输出证据，但三职业在噩梦下的完整真人可行性与平衡仍需验收。未编写新自动游玩AI。

本地旧纪录和快照均保留。2.0长局与2.1短局/新强度成绩不可直接作公平比较；本次未扩充历史库或清除存档。

## 测试及启动

核心测试 `pnpm test`，平衡测试 `tests/balance.test.ts`；原脚本 `scripts/balance-sim.ts`支持DIFFICULTY、SEED、NO_LUCK、PRIORITIES环境变量，保持原移动策略。固定站桩与Boss探针位于scripts/balance-probe.ts及boss-probe.ts。浏览器回归沿用browser-test、v2-test、full-game-test，发布验证使用release-test。

构建 `pnpm build`，本地 `pnpm serve`，开发 `pnpm dev`，离线 `pnpm build:offline`。本轮最终结果：TypeScript通过，41项核心测试通过；原浏览器10组、新增奖励/快照/无尽3组、完整战斗4组通过；生产网页及完全断网离线文件验证通过。实际查看了暴击、三连、领取回执截图，位于test-results。构建成功，仅保留原Phaser大文件体积提示。安卓真机、多种子真人长局、熟练走位与构筑的目标胜率尚未验证。请重点试玩噩梦三个职业、4分钟时构筑是否成型、Boss预警可读性、无尽成型后的压力和奖励反馈。

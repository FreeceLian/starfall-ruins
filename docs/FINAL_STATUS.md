# 星渊遗迹 1.0 · 功能清单

## 已实现

- 简体中文主菜单、三职业选择、帮助、设置、暂停、升级、身份事件、死亡、胜利与重开。
- 安卓浏览器目标的竖屏自适应界面；触屏摇杆和多指闪避，WASD/方向键、空格、Esc。
- 自动寻敌攻击，实体伤害、碰撞、敌人死亡和经验掉落、磁吸、升级三选一。
- 星刃骑士：穿透飞刃；虚空术士：范围爆裂法球与初始虚空印记；机械使徒：双无人机交替追踪射击与近身轨道伤害。
- 20种数据驱动升级；火焰持续伤害、寒冰减速、雷电传导、虚空易伤。
- 火冰熔裂：范围伤害；雷电与虚空引力坍缩：聚拢敌人并造成范围伤害。反应设有冷却以限制递归连锁。
- 三种普通敌人：蚀星兽、裂隙游魂、遗迹弩卫；两种精英：铁棘卫、星蚀祭司。
- 终焉守望者：第8分钟登场。三个血量阶段分别使用追击爆破、星环弹幕、密集多区域爆破。具有地面预警，击败即胜利；第11分钟遗迹崩塌，避免无限战斗。
- 第5分钟“你是谁”事件：教皇、小邝、博文、姚C、zzp、一飞、大肥羊、谁也不是。前六项随机小增益；大肥羊随机获得护盾、全场吸取或第三次攻击追加弹体之一；最后一项无增益。
- 战绩/设置本地存档与旧存档兼容，不需要游戏账号或AI服务。局内中途存档不在当前实现范围。
- 原创角色、五类敌人、Boss、场景、封面、动作帧、粒子、闪避残像、危机提示和Boss血条。
- 本地合成背景配乐与七类音效，分别调节音量、减少震动设置。
- 完整源码、静态构建、所有资源内嵌的单文件离线版本、来源及许可记录。

## 工程保护

- 固定逻辑步长，切后台暂停；控制输入在暂停、升级、重开时清除。
- 敌人90、星屑240、友方弹体80、敌方危险区域/弹体80、粒子150、浮字24、残像6、音频声部32上限。
- 星屑达到上限后合并经验总值，不丢奖励。消失实体对应精灵销毁；重开清除临时对象。
- 生产构建没有开发测试接口，没有运行时CDN或AI请求。

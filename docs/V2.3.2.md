# 2.3.2 本地修复验收

范围：蚀焰显示、密集攻击渲染开销、Boss 出生与绕障。未调整伤害、冷却、难度或协同效果；未发布公网。

## 确认的原因与修复
- 蚀焰原光环从很小的半径起步，容易被飘字遮挡；满16个反应特效后仍可显示反应文字但不新增光效。现在采用更大的紫橙光环，跟随目标；同目标重复反应刷新已有光效，满池复用即将结束的光效。
- 反应复杂图形原先逐帧重绘，密集攻击频繁创建飘字。现在预生成6张本地纹理、复用最多16个光效对象，并限制重复飘字和粒子生成频率。实际伤害及反应计算保持原样。
- Boss 原出生点仅单次推出障碍，追踪只尝试一个切向方向，不保证大型碰撞体能通过。现在出生位置位于靠近玩家的可通行区域，采用有限网格路线绕行；静止目标复用路线，移动目标最多每0.75秒重新规划，不增加实体上限。

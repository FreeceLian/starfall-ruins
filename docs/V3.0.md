# 3.0 主角视觉更新 · 本地验收

## 实现
- 用户提供的骑士王、虚空术士PNG原图以SVG容器内嵌，裁掉透明留白，不重新绘画。单张角色贴图同时包含武器、光环或法球；运行时各栅格化为126×192、140×192贴图。
- 机械使徒采用本项目绘制的悬浮机械核心SVG，裁边后162×192贴图。原有两架无人机及其战斗逻辑保持不变。
- 三职业显示框在390像素宽竖屏约85 CSS像素高（含头饰）。对应世界高度85×430/390；其它窗口随现有相机等比缩放，不是所有设备固定85像素。中心按人物身体而非含武器的贴图中心定位，脚下阴影与旧碰撞位置一致。
- 单精灵、轻微上下浮动；减少动态设置可关闭浮动，暂停冻结。闪避残影沿用现有上限并匹配新尺寸。新弹道分别为光剑、紫色法球、芯片弹。
- 无新增依赖、常驻粒子、独立武器对象或复杂动画；不修改游戏模型与战斗数值。

## 主要文件
public/assets/knight.svg、mage.svg、engineer.svg、shot-*.svg；src/render/scene.ts、art.ts；docs/ASSETS.md。菜单版本与package版本为3.0.0。scripts/hero-visual-test.mjs为针对性浏览器验证；stage2-test更新为静态圣像及轻浮动要求。

## 实际验证
- TypeScript与全部60项逻辑测试通过。
- hero-visual-test：三个职业85像素显示框、192像素高纹理、实际职业弹道、暂停冻结、闪避残影回收、减少动态、密集蚀焰特效上限、无页面错误通过。
- full-game-test：三职业、元素反应、身份奖励、Boss三阶段、胜利和重开通过。
- browser-test：触控/双指闪避、键盘、暂停、升级、死亡胜利、20次重开、六种窗口布局、后台暂停与资源加载通过。
- stage2-test：音乐设置持久化、圣像轻浮动、光剑实际发射和音频节点上限通过。
- 正式及离线构建成功，release-test确认4173和完全离线HTML可加载、战斗、暂停恢复，无外部网络依赖和开发接口。已查看三职业及密集蚀焰实际截图。构建仍有原Phaser大分块提示。
- 桌面Chrome，390×844，4倍CPU限速，现有术士密集穿透场景：接入前平均帧间隔18.15ms/P95 24.2ms，后18.44ms/P95 24.3ms；单次180帧采样，正常继续刷怪。这是方向性比较，不能证明所有设备性能相同。

## 限制与验收
本轮只在本地部署；等待用户验收，不发布公网。安卓真机、真人长时间游玩、所有构筑下的遮挡仍未验证。机械核心较宽，比两个人形主体显得更大，按用户批准保持85像素显示高度，主观比例需验收。

原图内嵌令源资源和离线包增大（当前离线HTML约8.90MiB，打包器在多个引用处重复内嵌）；GPU角色贴图仍固定192像素高，不逐帧处理原始大图。本轮不为减少包体扩展打包器改造。

未做独立巨剑/法球动画、多层呼吸发光、骨骼动画、新粒子或全场景重绘，以控制成本和性能。后续可考虑离线资源去重，但须另行确认。

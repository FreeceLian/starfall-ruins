# 第一批本地验收（2.1.1）

范围：怪物移速差异、无尽有上限加速、Boss耐久和节奏。元素、地形、伤害、升级、经验和2/4/6分钟时间线不改。仅供本地验收，不发布公网。

配置在src/data/config.ts：探索/挑战/噩梦的敌人移速分别×0.82/1/1.30，包含Boss，保留各敌人原始快慢差异。无尽初始×1，第4分钟后每分钟加0.06，最高×1.45（第11分30秒达到），持续作用于已存活敌人，寒冰仍有效；生命/伤害继续按2.1规则增长。最快普通敌人在无尽速度封顶时约119.8，低于未升级的最慢玩家145。

Boss基础生命4200→10500，基础移动速度32→44；三阶段攻击间隔2.7/2.4/1.8秒→2.3/2.0/1.6秒。没有增加伤害、技能、伤害免疫或强制最低战斗时间；预警时长不变。实际Boss生命：探索11340、挑战15750、噩梦24255、无尽初次15750。

固定15项常规升级、种子75、噩梦隔离Boss输出测试：三职业在测试无敌保护下约70/45/71秒击杀；无保护、近距离站桩均死亡。无敌仅用于测量输出窗口，不证明真人能稳定通关。探索/强力构筑允许更快，不强制所有人打一整分钟。

移速变化改变敌人的聚集和拾取顺序，难度并非严格单调：旧的“移除Boss后超成型构筑必须在119秒死亡”断言不再成立。最终参数下该场景生命由175最低降至约16.4，结束约23.5，受伤14次；测试改为验证显著受伤，未声称必死。真实Boss站桩死亡断言保持。没有为通过该样本添加伤害或卡组惩罚。

原有简易走位脚本、无幸运奖励、种子75进攻选择的噩梦全局样本，三个职业分别168/187/172秒死亡，尚未进入Boss战。因此完整真人通关机会、45—75秒实战战斗长度、是否过难都需要本地试玩；不能把受保护的Boss测试当成通关证明。

完整战斗浏览器脚本用于检查三阶段画面与交互；加速后的Boss会击杀静止测试角色，故开发专用boss测试入口增加10秒无敌让画面检查完成。正式生产包无此入口；死亡风险仍由核心测试单独验证。

启动：pnpm dev；构建：pnpm build；验收服务：pnpm serve，访问http://localhost:4173/，刷新后确认菜单底部2.1.1。离线包沿用pnpm build:offline。请先体验三档追击压力，再体验Boss时长、预警和闪避余地；确认本批后才进入后续开发。

验收前验证：42项核心测试通过；浏览器原有10组、完整战斗4组、奖励/纪录/无尽3组通过；TypeScript、网页及离线构建通过，生产网页与完全断网单文件验证通过。已查看Boss第三阶段实际渲染截图。安卓真机及真人完整通关仍待验收。

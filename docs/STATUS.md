# 功能与阶段清单

## 第一阶段已完成

- 可操作中文主菜单、操作说明、暂停、设置、死亡结算、试炼完成结算、重新开始。
- 手机竖屏布局，固定摇杆，多指同时移动和闪避；键盘移动、空格和 Esc。
- 星刃骑士：自动寻找最近目标，发射具有实际伤害的星刃；穿透升级真实影响命中数。
- 随机遗迹柱体布局、安全出生区、场地边界、柱体碰撞。
- 一种追击敌人（蚀星兽）：移动、障碍绕行、接触伤害、死亡、经验掉落。
- 经验磁吸、等级成长、升级三选一、累计经验连续升级。
- 八种可生效赐福：伤害、攻击间隔、速度、生命上限、吸取范围、穿透、闪避冷却、治疗。
- 闪避冷却、短暂无敌、受击保护间隔。
- 三分钟试炼终点，死亡和重新开始完整闭环。
- 本地战绩和设置存档、损坏存档容错、存储不可用提示。
- 原创 SVG 角色、敌人、石柱、封面和星徽；程序绘制地砖、星屑、星刃、打击特效。
- 基础合成音效、音量调节、减少震动设置。
- 敌人 90、星屑 240、飞刃 80、视觉粒子 150、伤害浮字 24 的上限；星屑超量合并保留经验总额。
- 完整源码、生产构建、独立离线 HTML 和测试报告。

第一阶段验收结果：核心循环与交互测试通过，可进入下一阶段。此结论不表示完整产品目标已实现。

## 第二阶段待完成

- 商业独立游戏级别的角色动作帧、完整技能动画、环境层次与美术精修。
- 配乐、丰富音效和更完善的战斗反馈；当前只有基础合成提示音。
- 安卓真机视觉、音频、帧率、温升和长时间游玩调优。

## 第三阶段待完成

- 虚空术士、机械使徒，以及三职业机制和平衡。
- 将升级扩展至至少 18 种。
- 火焰、寒冰、雷电、虚空四元素与至少两种可触发协同。
- 三种普通敌人、两种精英：当前仅一种普通敌人。
- 三战斗阶段的最终 Boss。
- 正式 8–12 分钟流程：当前为三分钟先行试炼。
- “你是谁”中后期彩蛋：教皇、小邝、博文、姚C、zzp、一飞、大肥羊、谁也不是；前六项随机小幅增益，大肥羊随机独特增益，谁也不是无效果。

上述内容均未放置冒充完成的按钮或占位技能。

## 第四阶段待完成

- 完整版本回归、长时间安卓真机测试、整体难度与节奏平衡。
- 公开部署与发布验证。本次仅提供本地服务器和离线包。
- 完整最终版本素材、许可、版本记录与发布包审查。

## 已知限制

- 随机柱体为第一阶段竞技场布局，不是房间串联式地下城。
- 追击 AI 只有基础切向绕柱，敌人之间没有刚体推挤。
- 局内存档/断点续玩未实现；当前保存历史战绩与设置。
- 难度尚未完成真人体验调优。测试通过不能替代 8–12 分钟完整版本的平衡验收。
- 浏览器滚动、虚拟按键与安全区已做适配，实体安卓设备仍待测试。

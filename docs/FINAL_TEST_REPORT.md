## 桌面渲染压力检查

`scripts/stress-test.mjs`：390×844，90敌人与Boss共同存在，持续24秒，测试接口给予无敌和零伤害以保持敌人数量。三次采样：

- 显示对象：117、117、117。
- 主动垃圾回收后JS堆：7.66、7.90、7.78 MiB。
- 敌方危险对象：23、2、1，均不超过80上限；其余实体与音频上限通过断言。
- 最后120次桌面无头浏览器动画回调：平均约6.03ms，P95约6.10ms。这是本机回调间隔，不是安卓设备或真实GPU帧率承诺。

没有在该短期压力窗口观察到持续增长；尚未做数小时内存/GC或实体安卓测试。
